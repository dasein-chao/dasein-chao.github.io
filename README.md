# 顿悟卡片

> 把你和 AI 辩论完就忘的那些「想通的瞬间」，变成能反复复习的卡片。

学习时经常有豁然开朗的时刻，或发现一个很难注意到的思维定势坑点，但忘得很快、不好描述、也不好复习。这个工具解决的就是这件事：

**贴进旧对话 → 自动找出卡点、提炼理解、生成助记和题目 → 存档 → 反复复习。**

## 有什么特点

- **不用装任何东西**：一个网页，双击就能用，不花钱、不填 key。
- **读的是你已有的对话**：不用在网页里重新聊，把之前和 AI 辩论的记录贴进来就行。
- **多种来源，选一下就能导入**：通用文本、无标记文本、ChatGPT、JSON、手动两段。想加新平台？加一个适配器即可。
- **双模式分析**：默认用本地规则抽取（开箱即用）；想要更深的理解，可填 key 接 AI（DeepSeek / 智谱 GLM / 自定义）。
- **一定要你自己润色**：生成的是草稿，用自己的话改过才算真正记住。
- **数据在你自己手里**：存在浏览器里，可导出/导入备份。

## 怎么用（30 秒）

1. 双击打开 `index.html`（或部署后用网页地址打开）。
2. 左侧「导入对话」→ 选对话来源 → 粘贴内容 → 点「生成卡片」。
3. 去「我的卡片」逐张润色：改标题、卡点、正确理解，写助记和题目。
4. 去「复习」抽卡自测。想不起来的会再次出现。

> 想快速试？把 `examples/示例对话-闭包.txt` 的内容贴进去，点生成即可。

## 给别人用 / 传到 GitHub

这是一个纯静态网页，免费托管最方便：

1. 把整个文件夹传到你 GitHub 仓库。
2. 仓库 **Settings → Pages** → Source 选 `main` 分支，保存。
3. 得到的网址发给别人，打开就能用——各自的数据存在各自的浏览器里，互不干扰。

别人想接自己的 AI：在「设置」里选预设、填自己的 API Key（只存本机，不上传）。

## 页面功能

| 页面 | 作用 |
|---|---|
| 导入对话 | 选来源 → 贴对话 → 本地分析或 AI 归纳 → 生成卡片 |
| 我的卡片 | 搜索、标签筛选、编辑润色、星标、新建 |
| 复习 | 抽卡翻面自评「忘了/模糊/记住了」+ 自测题 |
| 设置 | 配置 AI 模型、导出/导入备份、清空数据 |

## AI 模式（可选，不强制）

不填 key 时全程用本地规则分析，功能完整可用。填了 key 后在导入页勾选「用 AI 深度归纳」即可调用：

- **DeepSeek**：`platform.deepseek.com` 申请 key，预设已配好地址。
- **智谱 GLM**：`bigmodel.cn` 申请 key，设置里选 GLM 预设。
- **自定义**：任何 OpenAI 兼容接口，填地址和模型名。

## 文件结构

```
index.html          主页面
css/style.css       样式
js/importers.js     导入适配器（扩展新来源在这里 register）
js/analyzer.js      分析引擎（本地规则 + AI）
js/store.js         本地存储与备份
js/app.js           交互逻辑
examples/           示例对话
```

本地分析是规则提取，不是语义理解，难免有不精准的地方——这正是设计成「生成草稿 + 你来润色」的原因。
